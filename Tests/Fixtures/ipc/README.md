# Arrow IPC integration fixtures

These files are copied unchanged from the Apache Arrow testing repository:

- Repository: https://github.com/apache/arrow-testing
- Commit: `9ff285c88565f0f6abc855918c6a342e70e4909c`
- License: Apache License 2.0 (the repository's `LICENSE.txt`)

They are Arrow's integration "gold" files, generated by Arrow C++ 1.0.0.

| Directory | Source path in arrow-testing | Contents |
|---|---|---|
| `bigendian/` | `data/arrow-ipc-stream/integration/1.0.0-bigendian/` | `generated_<name>.arrow_file`, `.stream` and `.json.gz` for the names below, plus `generated_decimal.stream` and `generated_decimal256.stream` |
| `littleendian/` | `data/arrow-ipc-stream/integration/1.0.0-littleendian/` | `generated_<name>.stream`, the little-endian counterpart of each big-endian file |

Names: `custom_metadata`, `datetime`, `dictionary`, `dictionary_unsigned`, `extension`, `interval`,
`map`, `nested`, `nested_large_offsets`, `null`, `primitive`, `primitive_large_offsets`,
`primitive_zerolength`, `recursive_nested`, `union`.

The big-endian and little-endian files of one name hold the same values (pyarrow 25 reads them to
equal tables). The decimal files have no little-endian copy or JSON here, to keep the fixtures small;
their tests compare against pyarrow reading the same big-endian file.

Used by `Tests/ArrowMetalTests/IPCViewTests.swift` and `python/tests/test_ipc_views.py`.
